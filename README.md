# 🎢 Rollercoaster Ticket System

## 📌 Sobre o projeto

Este projeto consiste em um sistema de verificação de acesso e cálculo de ingressos para uma montanha-russa, desenvolvido utilizando Python.

O programa solicita a altura e a idade do usuário para verificar se ele atende aos requisitos mínimos para participar da atração. Caso seja permitido, o sistema informa o valor do ingresso de acordo com a faixa etária.

## 🎯 Objetivo

Desenvolver a lógica de programação por meio de estruturas condicionais, trabalhando com diferentes possibilidades de entrada e tomada de decisões.

## ⚙️ Funcionalidades

- Solicitação da altura do usuário em centímetros.
- Verificação da altura mínima de 120 cm.
- Identificação da faixa etária.
- Cálculo do valor do ingresso conforme a idade.
- Exibição de mensagens de aprovação ou restrição de acesso.

## 💻 Tecnologias utilizadas

- Python 3

## 📚 Conceitos praticados

- Variáveis
- Entrada de dados com `input()`
- Conversão de tipos com `int()`
- Estruturas condicionais (`if`, `elif` e `else`)
- Condicionais aninhadas
- Operadores de comparação.

## 🚀 Aprendizados

Com este projeto, pratiquei estruturas condicionais e condicionais aninhadas em Python, desenvolvendo um programa capaz de tomar decisões com base nas informações fornecidas pelo usuário.
